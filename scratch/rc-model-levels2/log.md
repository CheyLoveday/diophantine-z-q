# Results

- `BaseChange` passed targeted Lake build. The affine comparison sends the adjoined roots to the corresponding roots, the divisor restrictions commute with scalar extension, and `exactOrderBaseChange` applies the existing clopen comparison over every coefficient-ring map. All new proofs printed only `propext`, `Classical.choice` and `Quot.sound` or a subset.
- The first prerequisite check allowed Lake to launch several uncached modules concurrently. Subsequent Lake builds used a per-worktree compiler lock inside the required systemd CPU and memory scope.
- `FieldTests` passed targeted Lake build. Maximal residues detect units. Prime residues detect equality in a reduced algebra. Over a domain the exact-order algebra injects into its étale generic fibre by flatness and is reduced. The three axiom prints use only the permitted axioms.
- The extended `BaseChange` build verifies `torsionChartX`, `torsionChartY`, and preservation of both elements by affine torsion base change. The ordinate uses the root on the quadratic chart and zero on the branch. All four axiom prints use only the permitted axioms.
- `FibrePoints` passed targeted Lake build. It identifies maps from the exact-order algebra over a chosen coefficient point with exact-order points on the specialized curve, and checks numerator compatibility on the affine complement. Its axiom prints use only the permitted axioms.
- `ShortRepresentatives` passed targeted Lake build. Every pair class has a short-equation representative and a generator, over each field in which 2 and 3 are nonzero. The axiom print uses only the permitted axioms.
