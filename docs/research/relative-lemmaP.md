# Relative Lemma P for full level three

**Statement check (VERIFIED):** the frozen biadditivity condition normalizes the class on both zero axes. Twisting the pairing by a bundle pulled back from the base cannot produce another normalized pairing: pullback along the two zero sections recovers the base twist. The formulation also tests the fibre kernel on nonreduced schemes, so it does not equate triviality on geometric points with triviality of the scheme kernel. No counterexample to the relative statement was found. This check alone does not show that classes are determined by geometric fibres.
