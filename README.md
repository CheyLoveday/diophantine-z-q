# Diophantine Z in Q

- [Paper PDF](diophantine_zq.pdf)
- [Paper TeX source](diophantine_zq.tex)
- [Research handoff zip](https://github.com/elliotglazer/diophantine-z-q/releases/download/research-handoff-2026-11-04/z-in-q-research-handoff-2026-11-04.zip)
- [Release containing all three files](https://github.com/elliotglazer/diophantine-z-q/releases/tag/research-handoff-2026-11-04)

The paper files are the supplied versions, preserved byte for byte.

The research handoff contains saved research notes, manuscript revisions, failed approaches, Lean sources, computations, reviews, references, and remaining obligations. It excludes conversational transcripts and credentials. After extracting it, open `START_HERE.md` or the searchable `INDEX.html`. Its manifest preserves original paths and file hashes; the included restoration utility reconstructs the indexed research tree.

`SHA256SUMS` lists the checksums of the paper files and handoff archive. The handoff is stored as a release asset because it exceeds GitHub's ordinary Git file-size limit.
