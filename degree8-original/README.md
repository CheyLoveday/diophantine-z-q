# Inherited compiler and arithmetic evidence

These selected files document the base compiler and arithmetic inputs used by
the [Version 2 quartic](../quartics/quartic-12504/README.md). They are evidence
for a construction stage, not a third final polynomial in the manuscript.

The [current dependency inventory](../docs/quartic-12504/README.md) identifies
which statements are inherited and which are replaced by the reciprocal
logarithm argument. In particular, the current source uses beta precision 16
and requires its own arithmetic proof.

The historical notes retain their original wording, paths and review scopes.
This directory is a selected evidence collection, not a copy of the older
complete distribution. Run the [current reproducibility package](../quartics/quartic-12504/reproducibility/README.md)
for the supported end-to-end checks and their exact input files.
