# Assembly sources

These are exact copies of the reviewed assembly scripts, their intermediate manuscript, the construction fragment and assembly metadata. The scripts retain their original working-directory conventions. `SOURCE_MAP.json` maps those source locations to the files shipped in this repository, including the current final TeX and four reviewed exports.

Intermediate metadata retains the status assigned when that stage was created. It does not override the later accepted assembly or analytic reviews. The current reviews are under `docs/quartic-962-validation/` and `docs/quartic-962/evidence/`. Their scope is recorded in the source inventory and handoff descriptor.
