# Error verdict: the inherited all-index ring encodes the wrong quotient

At `diophantine_zq.tex` L770–773 (citation L11053–11057), the manuscript uses
Shimura's quotient construction. The inherited Lean claim in
`ShimuraThm1AsPrinted` that this construction gives `PrintQuotient` for
every family with `XiAction` is false with the base revision's all-index
`printRing`. This is an error in the Lean encoding of the cited step.
The identification of the kernel with the subvariety generated by the
annihilator images is in the proof on p. 526.

Both `XiAction` and `PrintedClauses` test only positive indices. Replace
`ξ 0` by the identity of the Jacobian in a genuine instance. The hypotheses
and Shimura's subvariety are unchanged. But the inherited ring includes
`(1, 0)`, since a cusp form has `ak f 0 = 0` (used in `xi_mem`).
The identity is then in the annihilator and its saturation (multiplier
`1`), so the killing conjunct forces `ν = 0`. This contradicts
surjectivity onto `A` of dimension `[K_f : ℚ] ≥ 1`. The same argument
rejects the previous run's proposed split input with the inherited ring.
